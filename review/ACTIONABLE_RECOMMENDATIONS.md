### 📌 Task ID: IMP-01 — แก้ไขการทับซ้อนของพื้นที่สัมผัส (Tap-Area Collision Resolution)
- **Priority:** P0 (Launch Polish)
- **ไฟล์เป้าหมาย:** [`public/content/rooms.json`](../public/content/rooms.json), [`public/js/house.js`](../public/js/house.js), [`tools/probe.mjs`](../tools/probe.mjs)
- **ปัญหาที่พบ:** จากผลการทดสอบ `npm run probe` พบว่า 32% ของบ้านมีการซ้อนทับของ Hitbox เกินเกณฑ์ โดยเฉพาะคู่:
  1. `fr-shoes` + `fr-floor-d` ซ้อนทับกัน **45%** (หน้าบ้าน)
  2. `fr-door` + `fr-floor-b` ซ้อนทับกัน **33%** (หน้าบ้าน)
  3. `fr-floor-d` + `fr-car` ซ้อนทับกัน **16%**
- **แนวทางแก้ไข (Solution):**
  1. ปรับค่าพิกัด `cx` (จุดกึ่งกลางแนวนอน) ใน `rooms.json` ของ `fr-shoes` ให้อยู่ทางซ้ายมากขึ้น (เช่น จากเดิม 160 เป็น 140) และเลื่อน `fr-floor-d` ไปทางขวา
  2. เพิ่มกฎ `excludes` ใน Slot definition เพื่อไม่ให้ระบบสุ่มเลือก Slot ที่อยู่ชิดกันมาวางพร้อมกันในบ้านหลังเดียวกัน
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - รัน `npm run probe` แล้วผล Overlap สูงสุดต้องลดลงเหลือไม่เกิน **10%** และไม่มีคู่ใดซ้อนทับกันเกิน 15%

### 📌 Task ID: IMP-02 — เพิ่มสัญญาณบอกตำแหน่งวัตถุที่แตะได้ (Affordance Indicator)
- **Priority:** P0 (Usability & Inclusivity)
- **ไฟล์เป้าหมาย:** [`public/css/app.css`](../public/css/app.css), [`public/js/scene.js`](../public/js/scene.js)
- **ปัญหาที่พบ:** ผู้เล่นใหม่ โดยเฉพาะเด็กและผู้สูงอายุ มองไม่ออกว่าวัตถุใดในรูปวาดสามารถแตะได้ เกิดปรากฏการณ์ "Pixel Hunting" หรือการจิ้มสุ่มไปทั่วจอ
- **แนวทางแก้ไข (Solution):**
  1. ในช่วง 5 วินาทีแรกของรอบ หรือเมื่อผู้เล่นไม่ได้แตะอะไรเลยเกิน 4 วินาที ให้สั่งคลาส CSS `.interactive-pulse` ให้วัตถุที่ยังค้างอยู่กระพริบประกายเบาๆ (Subtle Shimmer / Sparkle)
  2. หรือเพิ่มขอบเรืองแสงจางๆ (Soft Glow หรือ Breathing Outline) เมื่อวัตถุอยู่ในสถานะ `pending`:
     ```css
     @keyframes soft-pulse {
       0%, 100% { filter: drop-shadow(0 0 0 rgba(46, 155, 219, 0)); }
       50% { filter: drop-shadow(0 0 6px rgba(46, 155, 219, 0.45)); }
     }
     .item.pending .sprite {
       animation: soft-pulse 2.8s ease-in-out infinite;
     }
     ```
  3. ปิดแอนิเมชันนี้โดยอัตโนมัติหากผู้ใช้เปิดโหมด `prefers-reduced-motion`
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - ผู้เล่นใหม่สามารถระบุวัตถุที่แตะได้ทันทีโดยไม่ต้องจิ้มสุ่มฉาก

### 📌 Task ID: IMP-03 — ปรับปรุงกระบวนการบันทึกภาพใน In-app Browser ของ LINE
- **Priority:** P1 (Viral Enabler)
- **ไฟล์เป้าหมาย:** [`public/js/share.js`](../public/js/share.js), [`public/js/main.js`](../public/js/main.js), [`public/css/app.css`](../public/css/app.css)
- **ปัญหาที่พบ:** เบราว์เซอร์ภายในแอป LINE บล็อกคำสั่ง `download` ผู้สูงอายุไม่เข้าใจความหมายของข้อความ *"กดค้างที่รูป แล้วเลือก 'บันทึกรูปภาพ'"*
- **แนวทางแก้ไข (Solution):**
  1. เมื่อตรวจพบว่าเปิดอยู่บน LINE Webview (`inAppBrowser() === 'line'`):
     - แสดงไอคอนรูปมือนิ้วชี้จำลองแอนิเมชันกดค้างบนภาพการ์ดสรุปผล
     - เพิ่มปุ่มเด่นชัด: **"เปิดด้วยเบราว์เซอร์หลัก (Safari / Chrome)"** พร้อมไอคอนเปิดหน้าต่าง เพื่อให้ผู้ใช้กดดาวน์โหลดไฟล์ภาพเข้าเครื่องได้ทันที
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - ผู้ใช้ LINE ทุกวัยสามารถเข้าใจวิธีเซฟรูป หรือสามารถกดเปิดเบราว์เซอร์ภายนอกเพื่อบันทึกรูปได้อย่างง่ายดาย

### 📌 Task ID: IMP-04 — ลดความตื่นตระหนกจากเวลานับถอยหลัง (Timer Anxiety Relief)
- **Priority:** P1 (Elderly Accessibility)
- **ไฟล์เป้าหมาย:** [`public/content/strings.json`](../public/content/strings.json), [`public/js/main.js`](../public/js/main.js)
- **ปัญหาที่พบ:** ผู้สูงอายุตกใจกับแถบเวลานับถอยหลังสีฟ้า/เหลือง และระดับน้ำที่เริ่มขึ้นทันที ทำให้เกิดความกังวล
- **แนวทางแก้ไข (Solution):**
  1. เพิ่ม Micro-copy ชัดเจนในหน้าต่างคำแนะนำก่อนเริ่มเกม (How-to Modal):
     > 💡 **ไม่ต้องตกใจนะ:** เมื่อแตะสิ่งของเพื่อตอบคำถาม **เวลาจะหยุดเดินทันที!** ค่อยๆ อ่านได้เลย
  2. ในหน้าแรก (Start Screen) ให้มีตัวเลือกโหมดทางเลือก: **"โหมดซ้อมมือ (ไม่จับเวลา)"** หรือขยายเวลาเป็น 90 วินาที สำหรับผู้ที่ต้องการเล่นเพื่อศึกษาความรู้โดยเฉพาะ
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - ผู้เล่นกลุ่มผู้สูงอายุมีความมั่นใจและผ่อนคลายมากขึ้นในการเล่นรอบแรก

### 📌 Task ID: IMP-05 — ดึงเหตุผลหลัก "ทำไม?" ออกมาแสดงทันที (Instant Educational Value)
- **Priority:** P1 (Content Retention)
- **ไฟล์เป้าหมาย:** [`public/js/main.js`](../public/js/main.js), [`public/css/app.css`](../public/css/app.css)
- **ปัญหาที่พบ:** ปัจจุบันเหตุผลเชิงลึกถูกซ่อนไว้ใน `<details class="why">` ผู้เล่นส่วนใหญ่ (>75%) กดปุ่มเหลืองใหญ่ *"ไปต่อ / เข้าใจแล้ว"* ข้ามไปทันทีโดยไม่ได้เปิดดู
- **แนวทางแก้ไข (Solution):**
  1. นำประโยคสรุปเหตุผลหลัก 1 บรรทัดแรก (`why`) มาแสดงไว้ด้านล่างการ์ด `tip-card` ทันทีโดยไม่ต้องกดพับเปิด
  2. เก็บเฉพาะลิงก์อ้างอิงหน่วยงานรัฐ (Sources) และข้อความกฎหมายไว้ในปุ่มกางออก *"ดูแหล่งอ้างอิงทางการ ▾"*
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - ผู้เล่นได้รับความรู้เชิงลึกทั้งข้อแนะนำและเหตุผลเบื้องหลังโดยไม่ต้องเสียแรงกดเพิ่ม

### 📌 Task ID: IMP-06 — เพิ่มความเปรียบต่างทางสายตาในโหมดหลังน้ำลด (Return Mode Visuals)
- **Priority:** P2 (Visual Ergonomics)
- **ไฟล์เป้าหมาย:** [`public/art/rooms/`](../public/art/rooms/), [`public/art/sprites.svg`](../public/art/sprites.svg), [`public/css/app.css`](../public/css/app.css)
- **ปัญหาที่พบ:** ในโหมดหลังน้ำลด โคลนสีน้ำตาลเข้มและคราบน้ำทำให้สิ่งของขนาดเล็ก เช่น ตะขาบ, เศษแก้ว, ปลั๊กไฟที่เปียก กลืนไปกับพื้นเมื่อเปิดดูบนหน้าจอความสว่างต่ำกลางแจ้ง
- **แนวทางแก้ไข (Solution):**
  1. ปรับเพิ่ม Contrast ของ Sprite อันตราย เช่น เพิ่มเส้นขอบสีขาวบางๆ (White Keyline 1.5px) หรือปรับสีของคราบน้ำให้สว่างขึ้นจากพื้นดิน 15%
  2. เพิ่มเอฟเฟกต์ประกายสะท้อนแสงเบาๆ (Glint) บนเศษแก้วหรือจุดเสี่ยงไฟฟ้า
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - ผ่านมาตรฐาน WCAG AA ด้าน Contrast Ratio สำหรับกราฟิกอินเทอร์แอคทีฟ (≥ 3:1 เทียบกับพื้นผิวฉาก)

### 📌 Task ID: IMP-07 — พัฒนาเทมเพลตภาพส่งต่อวัฒนธรรมไทย (Thai Social Sharing Themes)
- **Priority:** P2 (Viral Amplification)
- **ไฟล์เป้าหมาย:** [`public/js/cards.js`](../public/js/cards.js), [`public/content/strings.json`](../public/content/strings.json)
- **แนวทางแก้ไข (Solution):**
  1. เพิ่มตัวเลือกสติกเกอร์หรือหัวข้อในการ์ดสรุปผลและเช็กลิสต์ เช่น:
     - *"ส่งต่อด้วยความห่วงใย เช้านี้ฝนตกดูแลบ้านด้วยนะ"* (สำหรับส่งยามเช้า)
     - *"น้ำลดแล้ว ค่อยๆ ตรวจบ้าน ปลอดภัยไว้ก่อน"*
  2. ปรับ Canvas Generator ใน `cards.js` ให้รองรับการเลือกลวดลายธีมวัน (ตามสีประจำวัน จันทร์-อาทิตย์) ซึ่งตรงกับรสนิยมการส่งภาพใน LINE ของผู้ใหญ่ไทย
- **เกณฑ์การยอมรับ (Acceptance Criteria):**
  - เพิ่มอัตราการดาวน์โหลดและแชร์ภาพเช็กลิสต์ในกลุ่ม LINE อย่างมีนัยสำคัญ
