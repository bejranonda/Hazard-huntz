`openssl s_client` at 20:43:38 UTC (through the proxy; the same tool showed GISTDA's real chain, so this is Air4Thai's own):

- **The fix, tested:** Let's Encrypt's `int-yr1.pem` and `root-yr-by-x1.pem` (Root YR cross-signed by ISRG Root X1; the system has ISRG Root X1 but not Root YR) as untrusted intermediates. `openssl verify` with the system roots: OK, leaf → YR1 → Root YR → ISRG Root X1 (YR1 alone still fails). curl `--cacert` (bundle plus both): 200. - **To watch:** the next leaf may come from YR2 or YR3; ship every Gen Y intermediate and cross-sign, or fetch AIA intermediates only from `*.i.lencr.org` and still verify to a system root; alert on failure; fall back to GISTDA.
